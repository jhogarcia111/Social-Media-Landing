# Brainstorming de Diseño - Landing Page "Mi Punto en el Mapa"

## Contexto
Landing page para vender servicios de gestión de redes sociales, creación de contenido y administración. Marca: "Mi Punto en el Mapa - Agente Multiplicador de Ventas". Paleta de marca: azul profundo, naranja, rojo coral, morado, con gráficos dinámicos.

---

## Opción 1: Energía Dinámica y Moderna (Probabilidad: 0.08)

**Design Movement:** Futurismo Digital + Brutalism Suave

**Core Principles:**
- Movimiento constante: elementos que flotan, giran y responden al scroll
- Contraste audaz: fondos oscuros con acentos de color neón (naranja, rojo coral)
- Asimetría radical: layouts desalineados que crean tensión visual
- Tipografía experimental: fuentes geométricas y sans-serif modernas

**Color Philosophy:**
- Fondo: Gradiente de azul profundo a negro (oklch(0.15 0.01 260))
- Acentos primarios: Naranja vibrante (#FF8C42) y rojo coral (#FF5757)
- Secundarios: Morado (#7C3AED) para CTAs
- Filosofía: Energía juvenil, tecnología de punta, movimiento constante

**Layout Paradigm:**
- Secciones con clip-path diagonales y ángulos irregulares
- Elementos flotantes que se mueven con el scroll (parallax)
- Grid asimétrico con columnas variables
- Superposición de capas con blur y transparencia

**Signature Elements:**
- Orbes/círculos animados que representan redes sociales
- Líneas dinámicas que conectan elementos (SVG animadas)
- Gráficos de crecimiento con animaciones de conteo

**Interaction Philosophy:**
- Hover effects con escala y rotación suave
- Botones que se expanden al pasar el mouse
- Transiciones de página con fade + slide
- Scroll triggers que activan animaciones

**Animation:**
- Duraciones: 300-400ms para interacciones, 600-800ms para scroll triggers
- Easing: cubic-bezier(0.34, 1.56, 0.64, 1) para bounce suave
- Stagger: 50-80ms entre elementos en listas
- Parallax sutil en secciones hero

**Typography System:**
- Display: "Space Grotesk" (bold, 3.5rem) para títulos principales
- Body: "Poppins" (regular 400, 500) para textos
- Accent: Monospace para números/precios
- Hierarchy: 3.5rem → 2rem → 1.25rem → 1rem

---

## Opción 2: Elegancia Corporativa Moderna (Probabilidad: 0.07)

**Design Movement:** Minimalismo Corporativo + Soft Modernism

**Core Principles:**
- Limpieza extrema: espacios en blanco generosos
- Tipografía sofisticada: fuentes serif + sans-serif balanceadas
- Sutileza en el movimiento: transiciones suaves y discretas
- Credibilidad visual: uso de fotografía profesional y datos reales

**Color Philosophy:**
- Fondo: Blanco puro (oklch(1 0 0)) con acentos azul corporativo
- Primario: Azul profundo (#1E3A8A) para confianza
- Secundario: Gris cálido (#6B7280) para textos
- Acentos: Naranja sutil (#F97316) solo en CTAs
- Filosofía: Profesionalismo, confianza, solidez

**Layout Paradigm:**
- Secciones con márgenes amplios y centrado
- Cards con sombras suaves (shadow-md)
- Dos columnas alternadas para contenido
- Espaciado vertical consistente (múltiplos de 2rem)

**Signature Elements:**
- Iconografía minimalista en línea fina
- Tablas de precios con diseño limpio
- Testimonios con avatares circulares
- Líneas divisoras sutiles

**Interaction Philosophy:**
- Hover effects discretos (cambio de color suave)
- Botones con transición de fondo
- Tooltips con información adicional
- Scroll suave sin animaciones agresivas

**Animation:**
- Duraciones: 200-300ms para todas las transiciones
- Easing: ease-in-out para suavidad
- Fade-in al cargar elementos
- Slide suave desde la izquierda en listas

**Typography System:**
- Display: "Merriweather" (serif, 3rem) para títulos
- Body: "Lato" (sans-serif, 400/500) para textos
- Accent: "IBM Plex Mono" para precios
- Hierarchy: 3rem → 1.875rem → 1.25rem → 1rem

---

## Opción 3: Vibrante y Accesible (Probabilidad: 0.06)

**Design Movement:** Diseño Inclusivo + Playful Modernism

**Core Principles:**
- Accesibilidad primero: contraste alto, tipografía legible
- Colores vibrantes pero armoniosos: paleta alegre sin ser caótica
- Interactividad clara: estados visuales obvios
- Inclusión de diversidad: iconografía y fotografía representativa

**Color Philosophy:**
- Fondo: Blanco suave con toques de azul muy claro (oklch(0.98 0.001 260))
- Primario: Azul vibrante (#2563EB) con alto contraste
- Secundario: Verde esmeralda (#059669) para éxito/crecimiento
- Acentos: Naranja (#FF8C42) y morado (#8B5CF6)
- Filosofía: Energía positiva, inclusión, claridad

**Layout Paradigm:**
- Secciones con padding generoso pero no excesivo
- Cards con bordes redondeados (radius-lg)
- Uso de iconografía grande y clara
- Espaciado vertical consistente y predecible

**Signature Elements:**
- Iconos grandes y coloridos (lucide-react)
- Badges con emojis para planes
- Gráficos de barras con colores degradados
- Botones con iconos integrados

**Interaction Philosophy:**
- Estados claros: focus, hover, active visibles
- Retroalimentación inmediata en interacciones
- Animaciones suaves pero notables
- Accesibilidad de teclado completa

**Animation:**
- Duraciones: 250-350ms para interacciones
- Easing: cubic-bezier(0.23, 1, 0.32, 1) para salida snappy
- Pulse suave en CTAs principales
- Bounce suave en hover de botones

**Typography System:**
- Display: "Outfit" (bold, 3rem) para títulos
- Body: "Open Sans" (regular 400/500) para textos
- Accent: "Courier Prime" para datos
- Hierarchy: 3rem → 1.875rem → 1.25rem → 1rem

---

## Decisión Final

**Se elige: Opción 1 - Energía Dinámica y Moderna**

Esta opción es la más alineada con:
- La energía del video del personaje animado (estilo Pixar)
- La paleta de colores vibrante del logo (azul, naranja, rojo, morado)
- El mensaje de "multiplicador de ventas" (dinamismo, crecimiento)
- La audiencia objetivo (emprendedores y pequeños negocios que buscan innovación)

La combinación de movimiento, asimetría y colores audaces creará una landing page memorable que destaque en el mercado.
